## 炭素固定源崩壊と自然循環崩壊から温暖化を理解する

地球温暖化は、しばしば「CO₂排出が多すぎる問題」として説明される。

この説明は重要であり、間違いではない。

CO₂は主要な温室効果ガスであり、大気中CO₂濃度の増加は温暖化の直接要因である。

しかし、より深い問いは次である。

> **なぜCO₂は大気中に蓄積し続けるのか。**  
> **なぜ地球は炭素を吸収し、固定し、蓄え、循環させる力を失いつつあるのか。**

このポータルは、地球温暖化と気候変動を、排出だけの問題ではなく、**炭素固定システムの弱体化、自然循環の崩壊、土壌・海洋代謝の低下、生物的炭素吸収源の崩壊**として整理する。

## 概要

地球温暖化は、単一原因だけで説明できる問題ではない。

一般的な理解では、温暖化は次のような直線モデルで説明されることが多い。

```text
人間活動がCO₂排出を増やす
CO₂が大気中で熱を閉じ込める
地球が暖まる
したがってCO₂排出を減らせば温暖化は解決する
```

このモデルは間違っていない。

しかし、不完全である。

大気中CO₂濃度は、排出量だけで決まるわけではない。

それは、地球システムがどれだけ炭素を吸収し、固定し、貯蔵し、循環できるかによっても決まる。

以下のシステムはすべて、炭素固定・炭素循環システムである。

```text
森林
土壌
湿地
海洋
微生物生態系
植物プランクトン
海草・海藻場
有機物循環
腐植・堆肥システム
```

これらが劣化すると、地球は炭素を処理する能力を失う。

その結果、CO₂は大気中に残りやすくなり、熱が蓄積し、気候不安定化が進み、さらに生態系劣化が進行する。

## 因果フィードバック構造

本ポータルの基本的な因果構造は以下である。

```text
人間活動
→ 森林・土壌・海洋・微生物システムの劣化
→ 炭素固定システムの弱体化
→ 炭素吸収・炭素貯蔵能力の低下
→ 大気中CO₂滞留の増加
→ 地球温暖化
→ 熱ストレス・干ばつ・海洋成層化・循環低下
→ 森林・土壌・海洋のさらなる弱体化
→ 炭素固定能力のさらなる崩壊
```

つまり、地球温暖化は以下の複合問題として理解する必要がある。

```text
CO₂排出
炭素固定源崩壊
自然循環崩壊
地球代謝の弱体化
土壌・海洋劣化
微生物減少
生物的炭素吸収源の喪失
```

したがって、有効な気候対策には、排出削減だけでなく、炭素固定システムの再生が必要である。

## 中心命題

このプロジェクトは、CO₂の温室効果を否定しない。

むしろ、CO₂蓄積を、炭素を吸収し、固定し、貯蔵し、循環させる自然システムの劣化と合わせて理解すべきだと考える。

要点は以下である。

> **CO₂は原因であると同時に、症状でもある。**

CO₂は温暖化の直接的な物理要因である。

同時に、CO₂が大気中に蓄積し続けることは、地球システムの炭素循環能力が弱まっていることの症状でもある。

もし気候政策が排出削減だけに集中し、炭素固定システムの崩壊を無視するなら、温暖化の因果構造を十分に扱えない。

## 1. 一般的な温暖化理解

一般的な説明は以下である。

```text
人間活動がCO₂排出を増やす
CO₂が温室効果を強める
地球が暖まる
したがってCO₂排出を減らす必要がある
```

この理解は科学的に重要であり、軽視すべきではない。

しかし、それは主に炭素循環の「排出側」に焦点を当てている。

十分に扱われていないのは「吸収・固定側」である。

```text
森林はどれだけCO₂を吸収しているのか
土壌はどれだけ炭素を貯蔵しているのか
植物プランクトンはどれだけ炭素を固定しているのか
有機物はどれだけ生態系へ戻っているのか
土地劣化・海洋劣化・微生物崩壊によって炭素循環はどれだけ壊れているのか
```

大気中CO₂は、排出だけで決まらない。

排出、吸収、固定、貯蔵、循環のバランスで決まる。

## 2. 欠けていた因果構造

より深い因果構造は、以下のように表せる。

```text
人間活動
→ 森林破壊・土壌劣化・海洋生態系劣化
→ 微生物・植物・植物プランクトンの弱体化
→ 炭素固定システムの崩壊
→ CO₂吸収・炭素貯蔵の低下
→ 大気中CO₂滞留の増加
→ 地球温暖化
→ 熱ストレス・干ばつ・海洋成層化・循環低下
→ 森林・土壌・海洋のさらなる弱体化
→ 炭素固定システムのさらなる崩壊
```

これは単なる排出問題ではない。

それは、**地球代謝の低下**である。

地球には本来、以下の機能がある。

```text
炭素を吸収する
炭素を固定する
水を循環させる
土壌を再生する
熱を分配する
生命を維持する
```

これらの機能が弱まると、温暖化と気候変動は加速する。

## 3. CO₂は原因であり症状でもある

CO₂は、熱を大気中に閉じ込めるため、温暖化の原因である。

しかし、大気中CO₂が増え続けることは、地球の炭素循環システムが弱まっていることも示している。

この違いを無視すると、気候対策は表面的になる。

CO₂排出削減は必要である。

しかし、排出削減だけでは、森林、土壌、海洋、湿地、微生物、植物プランクトンは自動的に回復しない。

完全な気候戦略には、以下が必要である。

```text
1. CO₂排出削減
2. 炭素固定システムの再生
3. 自然循環の回復
4. 土壌・海洋代謝の再構築
5. 生物的炭素吸収源の強化
```

---

## 4. 炭素固定システムとは何か

炭素固定システムとは、大気中または水中の炭素を吸収し、生物量、土壌有機物、海洋生物、長期的な生態系貯蔵へ変換する自然システムである。

主な炭素固定システムには以下がある。

```text
森林
草地
湿地
土壌
微生物
海洋
植物プランクトン
海草・海藻場
サンゴ礁生態系
農地
腐植・堆肥システム
有機物循環
```

これらは単なる背景ではない。

地球の炭素代謝を担う能動的な構成要素である。

森林が減れば、炭素固定能力は下がる。

土壌微生物が崩壊すれば、土壌炭素保持力は下がる。

植物プランクトンが減れば、海洋炭素吸収は弱まる。

湿地や海藻場が消えれば、自然の炭素吸収源は消える。

したがって地球温暖化は、大気だけの問題ではない。

それは、生物圏、生態系、海洋、土壌システムの問題でもある。

---

## 5. 自然循環崩壊とは何か

自然循環とは、水、炭素、栄養、酸素、熱、生命が地球システム内を巡る働きである。

例を挙げる。

```text
雨が降る
水が土壌へ浸透する
微生物が有機物を分解する
植物が育つ
植物がCO₂を吸収する
落ち葉や草が土へ戻る
土壌が炭素を保持する
川が栄養塩を海へ運ぶ
海で植物プランクトンが育つ
海洋がCO₂を吸収する
生命が循環を再生する
```

この循環が機能しているとき、地球は安定する。

しかし現代文明は、以下によってこの循環を壊してきた。

```text
森林破壊
単一植生の人工林
農薬の過剰使用
化学肥料への過度な依存
土壌微生物の減少
湿地破壊
河川改変
海洋汚染
乱獲
都市のコンクリート化
都市ヒートアイランド
食品廃棄物の焼却
有機物の土壌還元不足
```

これらはすべて、炭素固定と自然循環を弱める。

## 6. なぜ脱炭素だけでは不十分なのか

脱炭素は必要である。

しかし、地球の吸収・固定能力が低下し続けるなら、脱炭素だけでは温暖化を十分に止められない。

排出削減は、さらなる損傷を減らす。

炭素固定源再生は、地球が回復する能力を取り戻す。

どちらも必要である。

バランスの取れた気候戦略には、以下が含まれるべきである。

```text
排出削減
森林再生
土壌再生
微生物回復
湿地再生
海洋循環回復
植物プランクトン活性化
有機物循環
ヒートアイランド低減
水循環回復
地球代謝への直接支援
```

炭素吸収源を再構築しなければ、気候政策は不完全なままである。

## 7. カーボンニュートラルとネットゼロの本当の意味

カーボンニュートラルやネットゼロは、単なる数値会計として理解されるべきではない。

それは、以下のバランスを回復することを意味するべきである。

```text
炭素を排出する
→ 炭素を吸収する
→ 炭素を固定する
→ 炭素を貯蔵する
→ 炭素を循環させる
```

もしネットゼロが、会計上の帳尻合わせ、炭素クレジット、オフセット制度だけで達成され、森林・土壌・海洋・微生物システムが劣化し続けるなら、地球システムは不安定なままである。

真のネットゼロには、地球が炭素を吸収し、処理する能力の回復が必要である。

## 8. 地球代謝

このプロジェクトでは、地球の統合的生命維持機能を **地球代謝** と呼ぶ。

地球代謝には、以下が含まれる。

```text
炭素吸収
炭素固定
炭素貯蔵
水循環
熱分配
土壌再生
海洋循環支援
酸素生産
生物多様性維持
安定した気候条件の維持
```

地球代謝が弱まると、温暖化と気候不安定化は加速する。

したがって気候対策は排出削減だけに集中すべきではない。

地球システムの代謝機能そのものを回復する必要がある。

## 11. まとめ

地球温暖化は、CO₂排出だけの問題ではない。

それは同時に、以下の問題である。

```text
炭素固定システムの弱体化
自然循環の劣化
地球代謝の低下
```

因果構造は以下のように要約できる。

```text
CO₂排出
+ 炭素固定源崩壊
+ 自然循環崩壊
+ 地球代謝の弱体化
= 温暖化と気候不安定化の加速
```

必要な対応は以下である。

```text
脱炭素
+ 炭素固定源再生
+ 自然循環回復
+ 海洋・土壌再生
+ 人工叡智による統合評価
```

CO₂排出削減は必須である。

しかし、それだけでは足りない。

地球は、炭素を吸収し、固定し、水を循環させ、生命を再生し、熱を分配する能力を取り戻さなければならない。

これこそが、気候安定化と持続可能文明の本当の基盤である。
